# Climate Change & Prediction Platform

This is a web application built with Streamlit and Plotly to analyze over 70 years of historical climate data in the Aral Sea basin and predict future environmental trends.

The project handles raw data preprocessing, missing value interpolation, and includes a machine learning pipeline to forecast future temperature, precipitation, and water-level metrics.

## Features
- **Historical Data Analysis:** Visualizing decades of climate and hydrological data using Plotly.
- **Machine Learning Predictions:** Forecasting future climate trends based on historical datasets.
- **Modular ML Pipeline:** Structured approach for data ingestion, transformation, and model training.

## Project Structure
- `data/processed/`: Contains cleaned datasets and ML outputs (e.g., `future_predictions.csv`, `aral_sea_master.csv`).
- `logs/`: Execution logs generated by the custom logger.
- `src/`: Core source code with a modular ML architecture.
  - `components/`: Modules for data ingestion, transformation, and `model_trainer.py` for predictive modeling.
  - `pipeline/`: End-to-end data and prediction pipeline scripts.
  - `logger.py` & `exception.py`: Custom logging and error handling.
- `app.py`: Main Streamlit application script.
- `requirements.txt`: Project dependencies.

## Technologies Used
- Python (Pandas, NumPy, Scikit-learn)
- Plotly for data visualization
- Streamlit for the web interface
